# StockTracker

StockTracker is a static web-based inventory management system designed to
help users manage products and monitor stock levels.

The system allows users to add, edit, delete, search, and filter products
while automatically displaying stock status and inventory statistics.

## Live Demo

[View StockTracker Live](https://is-project-2026.github.io/stocktracker-165947/)

## Features

- Add new products
- Edit existing products
- Delete products
- Search products
- Filter products by category
- Monitor stock status
- View inventory statistics
- Persistent data using browser localStorage
- Responsive interface
- Keyboard accessibility improvements

## Inventory Statistics

The dashboard displays:

- Total number of products
- Total units in stock
- Number of low-stock products
- Number of out-of-stock products
